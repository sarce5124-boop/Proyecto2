# Sistema de Alquiler de Vehículos

Proyecto desarrollado para el curso de Programación III.

El sistema permite gestionar el alquiler de distintos tipos de vehículos, incluyendo:

- Motos
- Bicimotos
- Cuadraciclos

## Funcionalidades principales

- Registro y consulta de clientes.
- Registro y consulta de vehículos.
- Alquiler de vehículos disponibles.
- Devolución de vehículos.
- Control del estado de los vehículos.
- Cálculo y gestión básica del proceso de alquiler.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven
